# Matterhorn Construction

Cinematic site for **Matterhorn Construction, LLC** — custom timber homes in Pagosa Springs, Colorado. Featured project: **Six Pines Ranch**.

## Stack

- TanStack Start + React 19
- Tailwind CSS v4
- Vite (dev on port 8080)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

## Project

Six Pines Ranch is a heavy-timber house under Pagosa Peak (37.44395°N, 107.06659°W) with a built stream, antler work, stone, and a porte-cochere.

Films on the site are generated from stills of the actual lot.

## Deploy

`npm run build` emits a Vercel-ready Nitro output. Connect this repo to Vercel and deploy.
